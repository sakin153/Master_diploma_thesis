# 🌍 World Creator - Генератор 3D сцен из текста

Система для автоматической генерации 3D сцен MuJoCo из текстовых описаний на русском и английском языках.

## 🚀 Быстрый старт

### Генерация сцены
```bash
python main.py "стол и две коробки на нем в каждой коробке по 3 яблока"
```

### Просмотр результата
```bash
python view_scene.py
```

## ✨ Возможности

- 🤖 **LLM-управляемая генерация** - понимает естественный язык
- 🎯 **Умное размещение** - автоматическое размещение объектов с учетом физики
- 🪑 **Правильная ориентация** - мебель у стен поворачивается к центру
- 📦 **Физика** - динамические объекты падают и взаимодействуют
- 🎬 **Интерактивный viewer** - просмотр и симуляция в реальном времени
- 💾 **Архивация** - автоматическое сохранение с метаданными

## 🛠️ Установка

### Требования
- Python 3.10+
- Ollama с установленной моделью
- MuJoCo

### Зависимости
```bash
pip install -r requirements-main.txt
```

### Проверка
```bash
# Проверить Ollama
python test_ollama.py

# Запустить тесты
python -m pytest tests/ -v
```

## 📖 Примеры

### Простые сцены
```bash
python main.py "стол"
python main.py "стол и два стула"
python main.py "кресло у стены"
```

### Сложные сцены
```bash
python main.py "столовая с большим столом и четырьмя стульями вокруг"
python main.py "офис с письменным столом креслом и книжным шкафом"
python main.py "стол и две коробки на нем в каждой коробке по 3 яблока"
```

### Просмотр
```bash
# Список всех сцен
python list_scenes.py

# Открыть последнюю
python view_scene.py

# Открыть конкретную
python view_scene.py saved_scenes/стол_*/scene.xml
```

## 🎮 Управление в Viewer

| Действие | Клавиша/Мышь |
|----------|--------------|
| Вращение камеры | Левая кнопка + движение |
| Перемещение | Правая кнопка + движение |
| Zoom | Колесико мыши |
| Пауза/Продолжить | Пробел |
| Сброс | Backspace |
| Выход | ESC |

## 🏗️ Архитектура

```
Текстовый запрос
    ↓
Расширение запроса (LLM)
    ↓
Выбор 3D моделей из каталога
    ↓
Планирование размещения (LLM)
    ↓
Universal Placement System
    ↓
Сборка MuJoCo XML
    ↓
Физическая симуляция
    ↓
Готовая сцена
```

## ✅ Исправленные баги

- ✅ **Кресла повернуты к стене** - теперь мебель у стен поворачивается к центру
- ✅ **Объекты зависают в воздухе** - коробки и яблоки теперь падают
- ✅ **LLM не отвечает** - автоматический выбор рабочей модели

## 🔧 Конфигурация

### LLM модель
Текущая модель: `deepseek-v3.1:671b-cloud`

Для смены модели:
```bash
# Автоматический выбор
python fix_ollama_model.py

# Или вручную в creator/llm/model.py
OLLAMA_MODEL = "qwen2.5:7b"
```

### Каталог моделей
- **EmbodiedGen**: 452 модели (автоматически загружается)
- **Локальные**: `assets/` (apple, table, box, crate)
