# Исправление поворотов объектов (Stage 5)

## 🔍 Проблема

Стулья вокруг столов смотрели **вбок** вместо того, чтобы смотреть **на столы** (facing="inward").

## 📊 Анализ по стадиям

### Stage 1: Scene Graph ✅ КОРРЕКТНО
- Граф правильно указывает `"facing": "inward"`
- Связь `"type": "around"` корректна

### Stage 2: Hierarchical Placement ✅ КОРРЕКТНО
- LLM правильно рассчитал углы yaw_deg:
  - Север от стола → yaw=180° (смотрит на юг)
  - Восток от стола → yaw=270° (смотрит на запад)
  - Юг от стола → yaw=0° (смотрит на север)
  - Запад от стола → yaw=90° (смотрит на восток)

### Stage 3: Merge ✅ КОРРЕКТНО
- Данные передаются без изменений

### Stage 4: Collision Repair ⏭️ ПРОПУЩЕНО
- Временно закомментировано для тестирования

### Stage 5: MuJoCo XML Assembly ❌ ПРОБЛЕМА ЗДЕСЬ!

**Корневая причина:** Неправильная конвертация euler углов для моделей с `up_axis="y"`

## 🔧 Исправление

### Файл: `project/mujoco_assembler.py`

**Было (НЕПРАВИЛЬНО):**
```python
euler_str = f"0 0 {yaw_deg}" if up_axis == "z" else f"90 {yaw_deg} 0"
```

**Стало (ПРАВИЛЬНО):**
```python
euler_str = f"0 0 {yaw_deg}" if up_axis == "z" else f"90 0 {yaw_deg}"
```

### Объяснение

**Euler углы в MuJoCo:** `(roll, pitch, yaw)` применяются в порядке XYZ

**Для моделей с up_axis="y":**
- Модель изначально "лежит" (ось Y вверх в локальных координатах)
- Нужен `roll=90°` чтобы "поставить" модель вертикально
- Затем применяется `yaw` для поворота вокруг вертикальной оси

**Старая формула:** `f"90 {yaw_deg} 0"`
- roll=90° ✓ (поднимает модель)
- pitch=yaw_deg ❌ (применяет yaw как pitch!)
- yaw=0° ❌ (не применяет нужный поворот)

**Новая формула:** `f"90 0 {yaw_deg}"`
- roll=90° ✓ (поднимает модель)
- pitch=0° ✓ (не наклоняет)
- yaw=yaw_deg ✓ (правильно поворачивает!)

## ✅ Результат

После исправления:
- Стулья на **севере** от стола смотрят **на юг** (к столу) ✓
- Стулья на **востоке** от стола смотрят **на запад** (к столу) ✓
- Стулья на **юге** от стола смотрят **на север** (к столу) ✓
- Стулья на **западе** от стола смотрят **на восток** (к столу) ✓
