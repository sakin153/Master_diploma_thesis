## Технические детали

**Язык**: Python 3.10+

**Используемые компоненты**:
- Universal Placement System (уже реализована)
- EmbodiedGenLoader (существующий)
- MujocoSimInterface (существующий)
- LLM для извлечения объектов (существующий)

**Изменяемые файлы**:
- `creator/runner.py` - полная переписка
- `main.py` - упрощение вызова
- `README.md` - обновление документации

**Удаляемые вызовы**:
- `solve_floor_placements()`
- `solve_wall_placements()`
- `solve_small_object_placements()`

**Новый пайплайн**:
```
query → LLM (извлечение объектов) → 
        EmbodiedGen (подбор моделей) → 
        Universal System (размещение) → 
        MuJoCo XML (экспорт) → 
        файл
```
