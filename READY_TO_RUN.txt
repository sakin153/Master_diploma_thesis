📋 ЧТО ДЕЛАЕТ СИСТЕМА:

1. LLM генерирует semantic plan:
   - Задает связи между объектами
   - Указывает смещение и расстояние
   - Определяет ориентацию

2. DistanceResolver:
   - Преобразует relative position → absolute coordinates
   - Обрабатывает направления (front, back, left, right)
   - Применяет расстояния

3. OrientationResolver:
   - Преобразует relative orientation → absolute angles
   - Обрабатывает facing directions
   - Вычисляет углы поворота

4. PlacementExecutor:
   - Размещает объекты ТОЧНО по плану
   - Без модификаций и оптимизаций

5. SceneAssembly:
   - Создает MuJoCo XML
   - Сохраняет все параметры

🎯 ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:

Для "стол и стул":

  ✓ Стул лицом к столу
  ✓ Стул на правильном расстоянии
