# API Documentation - Project Pipeline

## Stage 0: Prompt Expansion

**File**: `prompt_expander.py`

**Function**: `expand_prompt(query, prompt_model_fn=None, llm_model=DEFAULT_MODEL, verbose=True)`

**Input**: Short text query (e.g., "офис с 5 столами")

**Output**: `SceneSpec` object with:
- `room_type`: str
- `room_style`: str
- `estimated_objects`: list of `ObjectHint`
- `room_half_size`: float
- `anchor_objects`: list of str
- `expanded_description`: str

---

## Stage 1: Model Picking

**File**: `model_picker.py`

**Function**: `pick_models(scene_spec, catalog, llm_model=DEFAULT_MODEL, prompt_model_fn=None)`

**Input**: `SceneSpec` from Stage 0, catalog from `load_catalog()`

**Output**: List of dicts:
```python
[
    {"Model": "desk", "uuid": "abc123", "model_loc": "/path/to/model.glb", "_query_name": "desk"},
    ...
]
```

---

## Stage 2: Model Loading & Scaling

**File**: `model_loader.py`

**Function**: `load_and_scale_models(chosen_models)`

**Input**: List from Stage 1

**Output**: Same list with added fields:
- `size`: [width, height, depth] in meters
- `scale`: float (scaling factor)
- `_height_m`: float (actual height in meters)

---

## Stage 3: Room Sizing

**File**: `room_scaler.py`

**Function**: `compute_room_half_size(models, room_type="other")`

**Input**: Models from Stage 2, room type string

**Output**: `float` - room half-size in meters

---

## Stage 4: Scene Planning

**File**: `scene_planner.py`

**Function**: `generate_placement_plan(models, room_half_size, room_type, query, prompt_model_fn=None)`

**Input**: 
- Models from Stage 2
- Room half-size from Stage 3
- Room type and query strings

**Output**: List of models with added fields:
- `Pose`: {"x": float, "y": float, "z": float}
- `yaw_deg`: float (rotation in degrees)
- `is_static`: bool

**Features**:
- Semantic plan generation via LLM
- Distance and orientation resolution
- Collision detection and resolution (gradient + LLM fallback)

---

## Stage 5: MuJoCo Assembly

**File**: `mujoco_assembler.py`

**Function**: `assemble_mujoco_scene(placed_models, room_half_size, output_path, cache_dir=None)`

**Input**:
- `placed_models`: List from Stage 4
- `room_half_size`: float
- `output_path`: str (where to save XML)
- `cache_dir`: str (default: ".cache")

**Output**: `str` - path to generated MuJoCo XML file

**What it does**:
1. Converts .glb meshes to MuJoCo XML
2. Creates scene with floor, ceiling, lights
3. Positions objects with correct pose and physics
4. Handles missing models with fallback cubes
5. Validates compilation with MuJoCo

**Generated XML structure**:
```xml
<mujoco model="scene">
  <option timestep="0.002" gravity="0 0 -9.81" .../>
  <default>
    <geom condim="3" friction="0.8 0.005 0.0001" .../>
  </default>
  <asset>
    <texture name="grid" .../>
    <material name="grid" .../>
  </asset>
  <worldbody>
    <geom name="floor" type="plane" .../>
    <geom name="ceiling" type="plane" .../>
    <light name="light_main" .../>
    <include file=".cache/converted/model_0/model_0/model_0.xml"/>
    <include file=".cache/converted/model_1/model_1/model_1.xml"/>
    ...
  </worldbody>
</mujoco>
```

**Cache structure**:
```
.cache/
├── converted/
│   ├── model_0/
│   │   ├── model_0.obj
│   │   ├── model_0/
│   │   │   └── model_0.xml  ← Generated by obj2mjcf
│   │   └── textures/
│   ├── model_1/
│   │   └── ...
│   └── ...
└── worlds/
    └── scene_latest.xml  ← Final scene
```

---

## Complete Pipeline Example

```python
from project.catalog import load_catalog
from project.prompt_expander import expand_prompt
from project.model_picker import pick_models
from project.model_loader import load_and_scale_models
from project.room_scaler import compute_room_half_size
from project.scene_planner import generate_placement_plan
from project.mujoco_assembler import assemble_mujoco_scene

# Load catalog
catalog = load_catalog()

# Stage 0: Expand prompt
spec = expand_prompt("Стол и 5 стульев")

# Stage 1: Pick models
models = pick_models(spec, catalog)

# Stage 2: Load and scale
models = load_and_scale_models(models)

# Stage 3: Compute room size
room_half = compute_room_half_size(models, spec.room_type)

# Stage 4: Generate placement plan
placement = generate_placement_plan(
    models, room_half, spec.room_type, spec.expanded_description
)

# Stage 5: Assemble MuJoCo scene
world_path = assemble_mujoco_scene(
    placement,
    room_half,
    output_path=".cache/worlds/scene_latest.xml",
    cache_dir=".cache"
)

print(f"Scene saved to: {world_path}")
```
