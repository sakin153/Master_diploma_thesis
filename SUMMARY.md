### 1. Исправлены критические баги

#### 🪑 Баг: Кресла повернуты к стене
- **Проблема**: Мебель у стен поворачивалась лицом к стене вместо центра комнаты
- **Решение**: Изменена логика в `floor_solver.py` - теперь ориентация определяется по фактической позиции объекта, а не по constraints от LLM
- **Файл**: `creator/placement/floor_solver.py` (функция `_get_yaw_candidates_for_position`)
- **Статус**: ✅ Исправлено и протестировано

#### 🍎 Баг: Объекты зависают в воздухе
- **Проблема**: Коробки и яблоки помечались как статичные и не падали
- **Решение**: 
  - Увеличен порог объема для маленьких объектов (0.1 → 0.3 м³)
  - Все контейнеры автоматически динамические
  - Добавлено сохранение размеров через весь пайплайн
- **Файлы**: 
  - `creator/placement/universal_system.py` (функция `_generate_semantic_plan`)
  - `creator/placement/layout_solver.py` (функция `_solve_with_dfs`)
- **Статус**: ✅ Исправлено и протестировано

#### 🤖 Баг: LLM модель возвращает пустые ответы
- **Проблема**: Модель `qwen3.5:cloud` возвращала пустые ответы
- **Решение**: 
  - Создан диагностический скрипт `test_ollama.py`
  - Создан автоматический фикс `fix_ollama_model.py`
  - Система переключена на `deepseek-v3.1:671b-cloud`
  - Увеличен лимит токенов (100 → 2000)
- **Файл**: `creator/llm/model.py`
- **Статус**: ✅ Исправлено и работает

## 🚀 Как использовать систему

### Генерация сцены
```bash
# Простая сцена
python main.py "стол"

# Сложная сцена
python main.py "стол и две коробки на нем в каждой коробке по 3 яблока"

# Комната с мебелью
python main.py "столовая с большим столом и четырьмя стульями"
```

### Просмотр результата
```bash
# Список всех сцен
python list_scenes.py

# Открыть последнюю сцену
python view_scene.py

# Открыть конкретную сцену
python view_scene.py /tmp/ciare_fresh_*/worlds/scene_latest.xml
python view_scene.py saved_scenes/стол_*/scene.xml
```

### Управление в viewer
- **Левая кнопка мыши + движение**: вращение камеры
- **Правая кнопка мыши + движение**: перемещение
- **Колесико**: zoom
- **Пробел**: пауза/продолжить
- **Backspace**: сброс
- **ESC**: выход
