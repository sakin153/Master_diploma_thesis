# Проблема с Количеством Объектов

## Проблема
Запрос "стол и 3 стула" генерирует только 1 стол и 1 стул вместо 1 стола и 3 стульев.

## Причина
LLM на этапе `expand_prompt` может неправильно парсить количество объектов из запроса.

## Диагностика

Запустите тест, чтобы увидеть, что именно извлекает LLM:

```bash
python test_expand.py
```

Это покажет, как LLM интерпретирует разные запросы:
- "стол и стул"
- "стол и 3 стула"
- "стол и 4 стула"
- "2 стола и 8 стульев"

## Возможные Решения

### 1. Более явный запрос
Попробуйте более явные формулировки:
```bash
python main.py "один стол и три стула"
python main.py "1 стол и 3 стула"
python main.py "стол с тремя стульями вокруг"
```

### 2. Проверить промпт расширения
Файл: `creator/contexts_prompts/expand.py`

Промпт должен правильно извлекать количество из запроса.

### 3. Проверить seed
В `main.py` строка 26:
```python
seed = 42  # Фиксированный seed
```

Попробуйте изменить на:
```python
import time
seed = int(time.time())  # Случайный seed
```

### 4. Проверить лог расширения
Добавьте в `main.py` после строки 34:
```python
print(f"[DEBUG] Query: {query}")
print(f"[DEBUG] Seed: {seed}")
```

И посмотрите в консоли:
```
[prompt_expander] Expanding query: 'стол и 3 стула'
[prompt_expander] Expanded: ...
[pipeline] Objects: ['table', 'chair', 'chair', 'chair']  ← Должно быть 3 стула
```

## Ожидаемое Поведение

Для запроса "стол и 3 стула":
```
[pipeline] Objects: ['table', 'chair', 'chair', 'chair']
[pipeline] ✓ Placed 4 objects
[pipeline]   table: pos=(0.00, 0.00, 0.00)
[pipeline]   chair 1: pos=(0.00, 0.60, 0.34)
[pipeline]   chair 2: pos=(0.00, -0.60, 0.34)
[pipeline]   chair 3: pos=(-0.60, 0.00, 0.34)
```

## Если Проблема Сохраняется

1. Проверьте вывод `test_expand.py` - что именно возвращает LLM
2. Проверьте, что в логе показывает `[pipeline] Objects: [...]`
3. Если LLM правильно извлекает объекты, но система их фильтрует - проблема в другом месте

## Альтернативный Подход

Если LLM плохо парсит количество, можно использовать более описательные запросы:

```bash
# Вместо "стол и 3 стула"
python main.py "столовая с одним столом и тремя стульями вокруг стола"

# Вместо "2 стола и 8 стульев"
python main.py "столовая с двумя столами, у каждого стола по четыре стула"
```

Более длинные описательные запросы обычно работают лучше, чем короткие числовые.
